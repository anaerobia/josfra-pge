	Instructions

To use the utility Aquasim.c it is first necessary to set
up an SDP Toolkit environment.  To do that, you can go
to the top level of the Toolkit directory structure,
and enter:

cd bin
cd brand (where brand is sgi32, sgi64, or sun5)

source pgs-env.csh

or (for kshell)

. pgs-env.ksh

Then Aquasim.c can be compiled with the script 
"SGI64compile.csh" on an SGI machine, or by sourcing 
the script "SOURCE_ME.sun5."  The latter is a bit
different not only due to compiler flags but due to the
small default stacksize limits on a typical Sun; the first
line of the script puts the stacksize up to the maximum.

Next it is advisable to run "orbsim" with the input file
orbsimAqua.in . On the other hand, it is possible to pick
just a single day for which to run orbsim, but it is
necessary to run the next day as well because the simulator
will need data from the very end of the day, while orbsim
quits one time interval (usually 1 minute) earlier.

It is then necessary to set the PCF.  For SGI enter at
the command line, (in Cshell) "setenv PGS_PC_INFO_FILE PCF"
or for sun 5, use PCF.Sun5 in a similar way. It is actually 
safest to enter the full path of the PCF.

Finally, one executes the code.  For SGI the name is
"aquasimul" while the script for Sun5 generates "aquaSUN5".

The execution command line is the executable followed by
a string such as  1995-10-20  with a date in it.

The function next interrogates the user as to an offset in
seconds, which causes the data to start that far into the
day.  The offset must be positive and less than 60 s.
If the user wishes no offset, she/he should enter a carriage 
return.

The program has built-in default data for the variable
names and types.  These can be overridden if a file
"NameTable.txt" is present. An example file is provided.
To see the default names in the output, move this file 
elsewhere or rename it. 

The usable dates can be gleaned from the list ("list") of
files generated by orbsim.  This list is included in the
delivery.  Of course, the user can instead generate data 
files for another date.  Then the PCF must be altered. 
Remember, you need to choose a date from the list which 
has a following day included, because orbsim ends a tiny 
bit before end of day.
  
	FURTHER DEFINITIONS

This section may duplicate ICD documentation.  If there is
any conflict the ICD should prevail and this code may need
to be changed - please consult ESDIS if necessary (presently
Dan Marinelli).

The carry-out file variables as defined in NameTable.txt

GNC_SS_SCPOSECIX	Spacecraft position x coordinate
GNC_SS_SCPOSECIY	Spacecraft position y coordinate
GNC_SS_SCPOSECIZ	Spacecraft position z coordinate
GNC_SS_SCVELECIX	Spacecraft velocity x component
GNC_SS_SCVELECIY	Spacecraft velocity y component
GNC_SS_SCVELECIZ	Spacecraft velocity z component
GNC_SS_QATTIRU1 	inertial quaternion component 1
GNC_SS_QATTIRU2 	inertial quaternion component 2
GNC_SS_QATTIRU3 	inertial quaternion component 3
GNC_SS_QATTIRU4 	inertial quaternion component 4
GNC_SS_BDYRATETI	time of attitude in whole seconds from 1958-01-01
GNC_SS_BDYRATETF	fractional seconds add-on to previous
GNC_SS_BODYRATEX	inertial body rate about spacecraft x axis
GNC_SS_BODYRATEY	inertial body rate about spacecraft y axis
GNC_SS_BODYRATEZ	inertial body rate about spacecraft z axis
GNC_SS_STATWD02 	status word indicating quality of attitude data
